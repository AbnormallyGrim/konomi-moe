Seanime plugin

Lives inside Seanime, which already has the user signed in, so there's no Profile or account linking.

Places: its own page · tray popover · a row on Discover · a section on each title's page.

Decisions these wireframes raise

  • Desktop navigation: sidebar or top bar?
  • Details: side panel (grid stays visible) or centred window (today's prototype)? In the plugin, maybe Seanime's own title page instead.
  • Accounts: one "list source" account at a time, or merge several?
  • Not interested vs Exclude: "Not interested" also teaches the model a dislike; "Exclude" only hides.
  • Plugin extras: are the Discover row and the title-page fit verdict worth it, or just the page and tray?
